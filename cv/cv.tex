% ===================== CURRENT RESEARCH =====================
\cvsection{Current Research}

At UC Irvine, working with Prof.\ Sharad Mehrotra on the \textbf{TIPPERS} project
(Testbed for IoT-based Privacy-Preserving PERvasive Spaces), addressing efficient
query processing over heterogeneous sensor data in smart buildings without
compromising the privacy of the individuals that data describes. Related directions
include data processing in decentralized ledgers over geographically distributed data,
access control within blockchain frameworks, blockchain-backed crowdsourcing, and
embedding machine learning inside the database engine to accelerate analysis.
